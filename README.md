# Static Assets Demo

This repository is a small, dependency-free static HTML demo showing how to display local image assets in a simple card layout. The standalone `index.html` page uses inline CSS and includes a Grupo GR logo (`grupo-gr-logo.png`), a sample logo (`icons/logo.svg`), and an SVG placeholder illustration (`images/photo1.svg`). There is no JavaScript, backend, or build step; open `index.html` directly in a browser or serve the folder with a simple HTTP server to view the demo.
